Download Cutterly

The Cutterly panel for Adobe Premiere Pro on macOS.

Version · macOS Release notes and earlier versions
Download Cutterly.dmg

Before installing, quit Premiere Pro with ⌘Q — the panel loads only when Premiere starts.

Install

  1. Open Cutterly.dmg.
  2. Double-click Install Cutterly.pkg and go through the installer to the end.
  3. Open Premiere Pro and choose Window → Extensions → Cutterly.
  4. In the Account tab (👤), paste your subscription key and press Connect. Your plan and the hours left this month appear.

If macOS won't open the installer

Cutterly is not signed with an Apple Developer ID yet, so macOS may say “Install Cutterly.pkg” Not Opened. That is expected for now — open it one of these two ways.

Through System Settings

  1. Click Done in that window.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to the message about Install Cutterly.pkg, click Open Anyway and enter your Mac password.

Through Terminal

With Cutterly.dmg open, paste this into Terminal and enter your Mac password:

sudo installer -pkg "/Volumes/Cutterly/Install Cutterly.pkg" -target /

Updating

When a new version is out, the panel shows a bar at the top with an Update button that brings you here. Quit Premiere Pro before installing — the new installer replaces the old panel by itself.

Uninstalling

Run this in Terminal:

sudo "/Library/Application Support/Cutterly/uninstall.sh"
