Install

macOS

  1. Open Cutterly.dmg.
  2. Double-click Install Cutterly.pkg and follow the installer.
  3. Open Premiere Pro → Window → Extensions → Cutterly.
  4. In the Account tab (👤) paste your subscription key and press Connect.

If macOS won't open the installer

That's expected for now: Cutterly isn't signed with an Apple Developer ID yet, so macOS may say “Install Cutterly.pkg” Not Opened. Open it like this:

Through System Settings

  1. Click Done in that window.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to the message about Install Cutterly.pkg, click Open Anyway and enter your Mac password.
Or through Terminal

With Cutterly.dmg open, paste this into Terminal and enter your Mac password:

sudo installer -pkg "/Volumes/Cutterly/Install Cutterly.pkg" -target /

Windows

  1. Run Cutterly-Setup.exe.
  2. If a blue Windows protected your PC window appears, click More info, then Run anyway.
  3. In the installer click Next → Install → Finish.
  4. Open Premiere Pro → Window → Extensions → Cutterly.
  5. In the Account tab (👤) paste your subscription key and press Connect.

The blue window is expected

Cutterly isn't code-signed yet, so Windows doesn't recognise the installer. Two clicks get you through:

Windows protected your PC More info1 Don't run
Windows protected your PC Cutterly-Setup.exe Run anyway2Don't run

No Terminal needed on Windows.

Updating

When a new version is out, the panel shows an Update bar that brings you here. Quit Premiere Pro, then run the new installer over the old one — the same on macOS and Windows.

Uninstalling

macOS — run in Terminal:

sudo "/Library/Application Support/Cutterly/uninstall.sh"

Windows

Settings → Apps → Installed apps → Cutterly → Uninstall
